# UT Poker 營運儀表板

讀取 Google 試算表「每日報表」與「週年慶全免折抵報表」的營運儀表板，部署在 Vercel，網站需要密碼才能看。

- 前一日概況、日期／月份查詢
- 本月現況：客人、場次、優惠券、收益
- TLT 賽事、月份對比、週年慶全免折抵三個分頁

## 運作方式

- `index.html`：儀表板頁面。
- `runtime.js`：提供頁面所需的資料函式，向 `/api/data` 取資料。
- `api/data.js`：Vercel 伺服器用 Google 服務帳號讀試算表，只讀固定的分頁與範圍（3～12 月 TLT 報表、折抵報表兩個分頁）。
- `api/login.js`、`api/logout.js`：密碼登入，登入後 30 天內不用再輸入。

試算表由每天的排程任務更新；打開網頁或按「重新整理資料」就會讀最新內容。

## 第一次設定（約 10 分鐘）

### 1. 建立 Google 服務帳號
1. 到 Google Cloud Console（console.cloud.google.com），建立或選一個專案。
2. 「API 和服務」→「程式庫」→ 啟用 **Google Sheets API**。
3. 「IAM 與管理」→「服務帳號」→ 建立服務帳號（名稱例如 `ut-dashboard`，不需要任何角色）。
4. 點進服務帳號 →「金鑰」→「新增金鑰」→ JSON，下載金鑰檔。**這個檔案等同密碼，不要傳給別人或放進 GitHub。**
5. 記下服務帳號的 email（`...@...iam.gserviceaccount.com`）。

### 2. 把兩份試算表共用給服務帳號
在「每日報表」和「週年慶全免折抵報表」按「共用」，加入上面的服務帳號 email，權限選 **檢視者**。

### 3. 在 Vercel 設定環境變數
Vercel 專案 → Settings → Environment Variables，新增：

| 名稱 | 內容 |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_JSON` | 金鑰 JSON 檔的完整內容（整份貼上） |
| `DASH_PASSWORD` | 網站登入密碼（自己設定，建議 12 碼以上） |

設定好後到 Deployments 對最新一次部署按「Redeploy」，新的環境變數才會生效。

## 日常使用
- 網址打開 → 輸入密碼 → 看儀表板。
- 要換密碼：改 `DASH_PASSWORD` 後 Redeploy，所有已登入的人都會被登出。
- 新月份：試算表新增「12月TLT報表」這類分頁後，網站會自動讀到，不用改程式。

## 收益與計算方式
- 收益＝後台交班報表「行政費」那一列的「櫃檯」金額（月報表 Y 欄「行政費櫃檯」）。
- 行政費應收＝各級別人次 × 行政費，未扣折抵，只用來看各級別貢獻。
- 盈餘受店內限時行銷等額外提撥影響，不計算。
